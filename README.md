# Suck The Sea!

Проект игры для Roblox. Исходники, модели и готовая карта находятся в корне репозитория.

## Скачать проект

```sh
git clone https://github.com/ivantodosiuc-rgb/Ocean.git
cd Ocean
```

Обычный `git clone` загружает все файлы проекта. Подмодули не используются.

## Открыть карту

Откройте `build/SuckTheSea.rbxlx` в Roblox Studio через **File → Open from File**.

## Содержимое

- `src/` — исходники Luau: клиент, сервер, общие модули и тесты.
- `assets/` — исходные модели Blender, экспортированные модели и текстуры.
- `build/` — карта Roblox, резервные копии, отчёты и снимки проверок.
- `tools/` — инструменты сборки и проверки.
- `.skill-review/` — материалы проверки Skills и копии исходных коллекций с их лицензиями.

Исходники из `src/` не синхронизируются со Studio автоматически. Порядок работы с картой описан в `AGENTS.md` и файлах `*_NOTES.md`.
